## How it works

1. **Run the server.** Start one node locally or a self-discovering fleet
   across regions — no static configuration required.
2. **Connect a client.** Drop in the TypeScript SDK and connect with a JWT
   token; the room is derived from the token's grant.
3. **Scale media routing.** Streams are automatically forwarded over pipe
   transports to the nodes where subscribers actually are.
